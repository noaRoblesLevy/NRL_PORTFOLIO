# NRL Portfolio

Personal portfolio of Noa Robles Levy, served with GitHub Pages:
**https://noarobleslevy.github.io/NRL_PORTFOLIO/**

Plain HTML, CSS and JavaScript with no build step. To add a project, copy an `<article class="card">` block in `index.html` and set its `data-tags` to one or more of `software`, `network`, `quant` and `hardware` so the filters pick it up.

Preview locally:

```bash
python -m http.server 8000
```
